# Calcolatrice

Un piccolo progetto di esempio con funzioni matematiche di base.

## Funzioni disponibili

- `somma(a, b)` — restituisce la somma di due numeri
- `sottrai(a, b)` — restituisce la differenza tra due numeri
- `moltiplica(a, b)` — restituisce il prodotto di due numeri

## Come eseguire i test

```
pytest test_calculator.py
```
